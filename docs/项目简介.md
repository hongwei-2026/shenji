# FinanceOS 项目简介

**项目全称**：FinanceOS · AI 财务操作系统  
**定位**：以「操作系统工作台」形态交付的财务审计与协作平台  
**当前形态**：高保真 Web 桌面壳 + Flask 业务服务（可选 Electron 封装）  
**仓库**：https://github.com/yuhongming-2026/shenji  
**分支**：`feature/financeos-desktop`  
**文档版本**：V1.0 · 2026-08-06  

---

## 一句话介绍

FinanceOS 不是再做一个侧栏式财务后台，而是把财务审计能力做成可点击的桌面应用，并用 AI 作为系统级调度入口——登录即桌面，开口即开应用，数据进得去、风险看得见、报告出得来。

---

## 要解决什么问题

| 痛点 | 传统方式 | FinanceOS 思路 |
|------|----------|----------------|
| 工具碎片化 | Excel + 网盘 + IM + 多个网页 | 统一桌面工作台 |
| 导航成本高 | 深层级侧栏菜单 | 快捷方式 + 开始菜单 + AI 开应用 |
| 审计门槛高 | 冷冰冰规则与报告 | 仪表盘可视化 + AI 解释辅助 |
| 协作分散 | 改数、传文件、沟通割裂 | 表格编辑 / Files / Chat |
| 权限难讲清 | 看得见点不开 | 桌面一致 + 业务按角色开放 |

---

## 产品长什么样

- **桌面**：类 Windows 11 风格（壁纸、快捷方式、开始菜单、任务栏）
- **核心快捷方式**：仪表盘、表格编辑、AI、Files、Terminal、Browser、Import …
- **业务应用**：凭证 / 往来 / 发票 / 对账 / 审计分析 / 报告等独立窗口打开
- **AI**：桌面应用 + 任务栏命令框，支持自然语言/语音打开应用
- **浏览器**：Blink + Gecko 双路径；关键词默认百度搜索（代理渲染）
- **检索**：站内知识库（Meilisearch 优先，SQLite FTS5 回退）

> 说明：FinanceOS 是业务「操作系统隐喻」，**不是**自研 Linux 内核或完整发行版。

---

## 核心能力清单

1. **数据进入**：CSV / Excel / 截图导入  
2. **表格编辑**：在线校对与协同编辑  
3. **审计仪表盘**：三阶段审计概览与风险图表  
4. **规则分析与报告**：异常检测、评分、导出  
5. **财务作业模块**：总览、凭证、应收应付、发票、银行对账等  
6. **AI 调度与辅助**：开应用、建议相关工具、问答解释  
7. **本地沙箱**：用户级 Desktop/Documents + 受限终端  
8. **权限体系**：多岗位角色 + 公司功能包  

---

## 技术架构（摘要）

```
桌面壳 (HTML/CSS/JS)
   └─ 独立应用窗口 (iframe / chrome=os)
         └─ Flask API + 业务模块
               ├─ SQLite 业务/历史库
               ├─ 可选 Meilisearch
               ├─ Agent / 模型配置
               └─ data/userspace 用户沙箱
```

运行：`Gunicorn` 多线程；公网演示常用 `scripts/start-public.sh`（如端口 6006）。

## 目标用户

- 中小型会计师事务所（底稿初筛、报告草稿、协作）  
- 企业财务 / 内审（异常核查、流程沉淀）  
- 高校与培训（实验环境、学生角色）  
- 集成商（私有化 + 行业规则包）  

---

## 商业化方向（摘要）

- **SaaS 订阅**：席位 / 租户年费  
- **私有化许可**：License + 维保（敏感数据场景）  
- **用量加购**：模型 Token、存储、检索配额  
- **解决方案**：实施、规则包、培训认证  

包装示意：Basic（教学/试用）→ Pro（全模块+AI）→ Enterprise（私有化/本地模型/审计日志）。

---

## 当前进度与边界

**已具备**：Web OS 桌面、核心快捷方式、AI 开应用、Files/Terminal、双路径浏览器、百度搜索代理、导入→仪表盘主路径、角色权限、产品设计文档与使用说明书。

**边界披露**：双内核为体验层双路径；AI 不能替代持证注册会计师判断；外网搜索受目标站与网络策略影响；首期不做自研内核 / 完整 ISO。
