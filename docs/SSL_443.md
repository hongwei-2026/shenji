# 生产环境：标准 HTTPS（443）与权威 CA 证书

当前 AutoDL 自定义服务通常映射 **6006/6008 → 公网 HTTPS:8443**，便于快速演示，但浏览器地址栏会带非标准端口，不利于信任感。

## 推荐架构

```
用户 --443/HTTPS--> Nginx（Let's Encrypt / 商业 CA 证书）
                      |
                      +--反向代理--> gunicorn 127.0.0.1:6006
```

## 前置条件

1. 已备案或可用的域名，例如 `finance.example.com`，A 记录指向服务器公网 IP  
2. 开放防火墙 **80**（签发/续期）与 **443**  
3. 安装 Nginx 与 Certbot（或使用云厂商证书托管）

## 快速步骤（Let's Encrypt）

```bash
# 1. 安装
sudo apt update
sudo apt install -y nginx certbot python3-certbot-nginx

# 2. 复制示例配置（先用 HTTP 便于签发）
sudo cp scripts/nginx-443.conf.example /etc/nginx/sites-available/shenji
# 编辑 server_name 为你的域名
sudo ln -sf /etc/nginx/sites-available/shenji /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 3. 申请证书（自动改写为 HTTPS）
sudo certbot --nginx -d finance.example.com

# 4. 确保本机应用在 6006 运行
bash scripts/start-public.sh
```

## 证书注意点

- **权威机构**：Let's Encrypt、DigiCert、GlobalSign 等均可；避免长期使用自签证书  
- **自动续期**：`certbot renew` 已由 systemd timer 管理时无需手工操作  
- **HSTS**：证书稳定后再启用 `Strict-Transport-Security`  
- **AutoDL 临时实例**：无固定域名时仍可用平台提供的 `*.seetacloud.com:8443`；正式对外请迁到自有域名 + 443  

## 环境变量（可选）

| 变量 | 说明 |
|------|------|
| `DEMO_VIDEO_URL` | 登录页嵌入产品介绍视频（如 B 站/YouTube 嵌入地址） |
| `SITE_COMPANY_NAME` | 页脚展示的公司法定名称 |
| `SITE_COMPANY_ADDRESS` | 页脚地址/所在地 |
| `PUBLIC_PORT` | 应用监听端口，默认 6006（由 Nginx 反代，无需对公网暴露） |
